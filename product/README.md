# Product

What lablet is and why it exists. Read in this order:

1. [brief.md](brief.md) — the problem, the idea, and what is out of scope.
2. [spec.md](spec.md) — the design: architecture, domain model, ports, adapters, config, telemetry.
3. [quality-bar.md](quality-bar.md) — what we commit to for users and what the repository enforces.
4. [build-plan.md](build-plan.md) — the phased plan an agent follows to build it.
5. [acceptance.md](acceptance.md) — the scenarios and checklist that define done.
6. [decisions.md](decisions.md) — a dated log of decisions and the reasoning behind them.

Change a decision by appending to `decisions.md` and updating the spec, not by editing history.
