# Parity matrix

Researched 2026-09-24 and 2026-09-25, against Claude Code 2.1.281, Codex rust-v0.156.1 and mini-swe-agent v2.4.6. Each row is one behaviour that changes what lablet measures. The reference columns and "Lablet today" are inventory, and "Proposed" is opinion. The evidence for each reference cell is in that reference's document. "Field" summarises [field.md](field.md). "Needs capture" means only a recorded request can settle the cell.

The design review's decisions are recorded in `decisions.md`, 2026-09-28. The proposals mention them where they apply.

Lablet today is what [the spec](../../spec.md) says, and its status is one of:

- **same**: matches the primary reference
- **close**: differs in detail
- **differs**: behaves differently
- **gap**: lablet has no equivalent

Each proposal starts with a label, set by the two rules in [README.md](README.md):

- **Keep**: lablet already behaves this way
- **Default**: a default value changes
- **Build**: lablet adds a mechanism
- **Setting**: the harnesses split, so lablet offers both behaviours
- **Later**: inside the line, but its own feature, built when it's scheduled or when a transfer check calls for it
- **Difference**: outside the line, so it's recorded and not built

The mini-swe-agent column is evidence. It isn't a profile lablet reproduces.
