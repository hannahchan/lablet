# Parity matrix

Researched 2026-09-24 and 2026-09-25, against Claude Code 2.1.281, Codex rust-v0.156.1 and mini-swe-agent v2.4.6. Each row is one behaviour that changes what lablet measures. The reference columns and "Lablet today" are inventory, and "Proposed" is opinion. The evidence for each reference cell is in that reference's document. "Field" summarises [field.md](field.md). "Needs capture" means only a recorded request can settle the cell.

The design review of 2026-09-24 made decisions that aren't recorded in `decisions.md` yet. The proposals mention them where they apply.

Lablet today is what [the spec](../../spec.md) says, and its status is one of:

- **same**: matches the primary reference
- **close**: differs in detail
- **differs**: behaves differently
- **gap**: lablet has no equivalent
