# Parity matrix

Researched 2026-09-24 and 2026-09-25, against Claude Code 2.1.281, Codex rust-v0.156.1 and mini-swe-agent v2.4.6. Each row is one behaviour that changes what lablet measures. The reference columns and "Lablet at the survey" are inventory. The last column is what was decided or is proposed for the row. The evidence for each reference cell is in that reference's document. "Field" summarises [field.md](field.md). "Needs capture" means only a recorded request can settle the cell.

The decisions are in `decisions.md`, 2026-09-28, and the spec now says what they decided. A proposal that isn't marked as decided is opinion.

Lablet at the survey is what [the spec](../../spec.md) said on 2026-09-25, before those decisions changed it, and its status is one of:

- **same**: matches the primary reference
- **close**: differs in detail
- **differs**: behaves differently
- **gap**: lablet has no equivalent

Each entry in the last column starts with a label, set by the two rules in [README.md](README.md):

- **Keep**: lablet already behaved this way, and still does
- **Decided**: lablet changes, and the entry names the phase that builds it
- **Later**: inside the line, but its own feature, in phase 12
- **Difference**: outside the line, so it's recorded and not built

The mini-swe-agent column is evidence. It isn't a profile lablet reproduces.
